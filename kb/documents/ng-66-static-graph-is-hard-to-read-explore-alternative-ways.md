# NG-66: Static graph is hard to read — explore alternative ways to visualise it

Source: NG-66

Static graph is hard to read — explore alternative ways to visualise it

Type: Story
Status: In Review

The CMG static graph is currently not user friendly. For anything beyond a small repo it renders as a dense tangle of overlapping nodes and crossing edges — you cannot tell which service a node belongs to, what the layering is, or what depends on what. It looks impressive and communicates nothing, so nobody uses it to answer a real question.
