# NG-72: Mapping Logs to the Code

Source: NG-72

Mapping Logs to the Code

Type: Spike
Status: In Review

Goal / Problem Statement
To improve observability and root-cause analysis, we need to correlate runtime logs directly with the underlying codebase, automatically categorize log messages, and establish a centralized repository to store domain-specific log patterns
Key Questions to Answer
Log Collection: What are the exact log outputs, formats, and volumes generated by the local MovieLens project setup?

Span Categorization (span cat): How effectively does the local span cat model process MovieLens logs, and what are its performance/capability limits?

Pipeline / Bridge: How should the bridge code/pipeline be structured to route local MovieLens logs into storage without causing performance bottlenecks?

Database Evaluation: Which database solution best handles the unstructured data requirements (read/write throughput, query performance, schema flexibility) for this log mapping?
